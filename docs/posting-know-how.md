# 空手道場のチラシ各戸配布：地図アプリ調査＋プロの配布ノウハウ

調査日：2026年8月16日

---

## 0. 先に結論

**「配った家を塗りつぶしていく専用アプリ」で、個人が無料で使える決定版は事実上ない。**
ポスティング専用アプリのほとんどは配布業者が配布員を管理するためのシステム（管理者パネル契約が前提）で、一人親方には向かない。

現実的な最適解は、無料ツール3つの組み合わせ：

| 役割 | ツール | 料金 |
|---|---|---|
| **①エリアを決める** | jSTAT MAP（総務省統計局） | 無料（要メール登録） |
| **②区画を割る・計画する** | Googleマイマップ | 無料 |
| **③配った道を可視化する** | GPSロガーアプリ | 無料 |
| （+α）枚数を記録する | タウンノート | 無料 |
| （+α）建物名・戸数まで見る | ゼンリン住宅地図スマートフォン | 月990円（14日無料） |

キモは③で、**「歩いた軌跡＝配った道」**として記録する発想。専用アプリを探すより、GPSログを毎回スクショして地図に重ねるほうが早く、確実に重複配布が防げます。

## 1. 地図アプリ調査

### 1-1. 個人ポスティングに使えるツール比較

| ツール | できること | 料金 | 一人での使い勝手 |
|---|---|---|---|
| **Googleマイマップ** | エリアをポリゴンで囲って色分け、ルート線を引く、e-Statの町丁目境界データをインポート、スマホで現在地（青い点）を見ながら「今この区画の中か」を確認、URLで共有 | 無料 | ◎ 本命 |
| **GPSロガー**（私の路線／ルートヒストリー／Walkmeter 等） | 歩いた経路を自動記録。「線が引かれていない道＝まだ配ってない道」として判断できる | 無料 | ◎ 本命 |
| **タウンノート** | 町域単位で配布枚数・メモを記録、目標に対する進捗表示、複数プロジェクト管理、CSV出力。iOS/Android両対応 | 無料 | ◎ 記録用に |
| **jSTAT MAP** | 国勢調査データを地図に重ねる。道場から半径◯km／徒歩◯分の円を描き、その中の世帯数・年齢別人口（0〜14歳など）を集計。HTML/Excel出力 | 無料（要登録） | ◎ エリア選定用 |
| **ゼンリン住宅地図スマートフォン** | 建物一軒一軒に名前が入った住宅地図。マンション名・戸数まで見えるので事前の枚数見積もりが正確に | 月990円（税込）／申込から14日間無料 | ○ 精度を上げたいなら |
| **いつもNAVI**（ゼンリンデータコム） | 住宅地図系。無料版あり、有料は月数百円〜 | 無料〜 | ○ |
| **らくばるポスティング** | 配布経路をログとして地図に残す、空家・投函不可物件をピン登録。**ただし利用に管理パネルのユーザー作成が必要** | アプリ自体は無料 | △ 業者向け |
| **Mapion** | 「細道」レベルまでズームして配布用地図を無料で複数ページ印刷 | 無料 | ○ 紙派なら |

### 1-2. 注意点

- **Googleマップの「タイムライン」は2025年に仕様変更**され、履歴がクラウドから端末保存に移行、Web版も廃止されました。以前は「タイムラインで配った道を確認」というノウハウが定番でしたが、今は端末ごとの保存になり移行手続きが必要だったため、**専用のGPSロガーアプリを別に入れておくほうが安全**です。
- ゼンリン住宅地図スマートフォンはキャリア決済の新規受付が2025年12月で終了。クレカ決済（ZENRIN Store）で申し込みます。
- GPS系アプリはバッテリー消耗が激しい。モバイルバッテリー必携。

### 1-3. 「塗りつぶし」を自作する運用手順（推奨）

1. jSTAT MAPで道場を中心に半径1.5km／2kmの円を描き、町丁目ごとの世帯数と0〜14歳人口を出す
2. e-Statから町丁目の境界データをダウンロード、**Googleマイマップにインポート**して区画線を表示
3. 1回の配布で回る範囲（＝2〜3時間で終わる量）ごとにレイヤを分け、済んだ区画を**塗り色を変える**
4. 配布中はGPSロガーをONにして歩く
5. 帰宅後、ログのスクショを見ながらマイマップの区画を「済」色に更新＋タウンノートに枚数を記録

これで、専用アプリなしで「どこを・いつ・何枚配ったか」が完全に残ります。

> なお、町丁目ポリゴンをタップして「済／未」を塗り分けるだけの簡易Webアプリなら自作も現実的です（オフラインでもスマホで動く1ファイルのHTMLで作れます）。既存アプリで不満が出たら検討する価値あり。

## 2. プロの配布ノウハウ

### 2-1. 配布スピードの現実的な目安（徒歩）

| エリアの性質 | 全戸配布 | 戸建てのみ |
|---|---|---|
| 市街地（マンション比率70%） | **約400〜600枚／時**（目安500） | 約100〜150枚／時 |
| 郊外（マンション比率30%） | 約300〜400枚／時 | 約200〜250枚／時 |

- バイクは徒歩の**1.2〜1.3倍**程度。ただし乗り降りが頻繁なので、メリットは速度より疲労軽減。
- **自転車はポスティング向きとは言えない**（乗り降りの手間が大きい）とされます。移動用と割り切るのが吉。
- 配布枚数を最も左右するのは「マンションと戸建ての比率」。集合住宅が多いエリアほど枚数が伸びる。

### 2-2. ルートの組み方

- **一筆書きにする** — エリア全体を右回りか左回りのどちらかに決め、往復をなくす
- **集合住宅を先に処理** — まとめて配れるので時間効率が圧倒的に良い
- **戸建ては道の片側ずつ**（奇数側→偶数側）— 道を横断しないので歩行距離が半減
- 自転車・バイクは**公園など目立つ場所に停める**。停めた場所を忘れると1時間以上のロスになる

### 2-3. 手さばき（ここが一番差が出る）

- **指サック**を利き手の親指と中指に。100均で買える。チラシを1枚ずつ取るのは想像以上に難しく、これだけで大きく変わる
- バッグは**斜め掛けか両肩掛け**。片肩掛けは肩を壊す。1回に持つのは**5kg以内**
- バッグの**開口部を体の前**に向けてサッと取り出せる状態に
- **10枚ずつ軽く折って区切る**と取り出し速度が上がる（枚数カウントも兼ねる）
- **投函は利き手だけ**。もう一方の手はバッグに置いておき、両手を使わない
- 歩きながら**次のポスト位置を目で探す**。立ち止まる回数を減らす
- 複数種類を配るなら、内側に2種を50部ずつ、1種を外ポケットからはみ出させて置く

### 2-4. マンション攻略

- ポストの場所は3パターン：**入口付近／側面のメールボックス室／建物裏側**。この順に見る
- **大型マンションは朝7時頃**が狙い目。郵便配達員や住人と鉢合わせず、邪魔にならない
- 管理人の許可が要るケースもある。揉めそうなら潔く飛ばす

### 2-5. 体力・季節対策

- 背筋を伸ばして**大股で歩く**と疲れにくい
- **20分ごとに少量ずつ水分補給**、**100枚配るごとに30秒休憩**
- 夏：半袖の上に薄手の長袖スポーツウェア。日焼け対策になり実際は涼しい
- 冬：**指開き手袋は必須**。指が動かないと作業にならない。防寒ブーツ（2〜3千円）も
- 物陰から犬に吠えられる・急に怒鳴られることがある。常に警戒を

### 2-6. 法務・トラブル回避（道場の看板を背負う以上、ここは重要）

- ポスティング自体は違法ではない
- ただし**「チラシお断り」「投函禁止」の表示がある家・建物には入れない**。刑法130条（住居侵入）や軽犯罪法1条32号（立入禁止場所への侵入）に触れうる
- **オートロックの内側に入らない／上階まで上がらない**。政党ビラの配布で3〜7階まで立ち入り有罪となった「葛飾事件」がある。一方2021年の最高裁判断では、管理組合の意向に反しても玄関部分への立ち入り＋1枚投函は直ちに違法とはいえないとされており、**1階のポストに1枚**なら実務上まず問題にならない
- 宛名（「◯◯様」）を書いたものを投函すると郵便法違反になりうる。宛名は入れない
- **配布禁止リストを作って必ず残す**。同じ家で2回目のクレームは致命的
- 苦情が来たら即謝罪＋回収。地元の道場は評判がすべて

## 3. 空手道場としての配布設計

### 3-1. 反響率の現実を先に知っておく

- 学習塾・スポーツジムのポスティング反響率は**0.01〜0.03%＝1万枚で1〜3件**（体験申込ベース）
- つまり**300枚配って反応ゼロは異常ではなく正常**。ここを知らずに「効果がない」と判断してやめるのが最大の失敗
- 逆に言えば、**年間1万枚配って体験3件・入門1〜2件**が標準的な打率。一人あたりの生涯価値（月謝×在籍年数）で考えれば十分ペイする計算になるはずです

### 3-2. エリアの決め方：距離がすべて

- 武道道場は**商圏が狭い**。通いやすさと稽古の曜日・時間帯が入門の決め手になるため、送迎できる範囲が実質的な全部
- ポスティング業界の知見でも、**年齢構成の差より距離のほうが圧倒的に効く**（隣接する町丁目の年齢分布の差はせいぜい1〜5%しかない）
- **最優先：既存の門下生の住所を全員Googleマイマップにプロット**する。実際に人が来ているエリアが可視化される。これが一番確実な商圏地図です
- 次に**小学校区を単位**に考える。少年部が主力なら、学区は通学班・保護者ネットワークとほぼ一致するので、面ではなく学区で攻める
- jSTAT MAPで**0〜14歳人口の多い町丁目**を出し、距離が同程度なら子どもの多いほうを先に

### 3-3. 撒き方の設計

- **薄く広くより、狭く繰り返す**。ザイアンス効果（接触回数で親近感が生まれる）を狙い、同じエリアに3〜6ヶ月にわたって、あるいは年4回（季節ごと）配る
- 集合住宅は効率がいいが、**ファミリー向け分譲・団地・3LDK中心の物件を優先**し、単身ワンルームは捨てる。ゼンリン住宅地図があるとここの判別が早い
- **タイミング**：主婦・ファミリー狙いなら投函は**10時〜15時**（ポストを見る時間帯）。曜日は土曜がじっくり読まれるが競合チラシも多いので、あえて平日を選ぶ手も
- **時期**：4月の新学期、9月の新学期、年明け（新しいことを始めたい時期）の直前3〜4週間に集中

### 3-4. チラシの中身（配布と同じくらい効く）

- ポストから抜いて捨てるまでの判断は**2秒**。文字を減らし、画像とキャッチで「何のチラシで、あなたに何のメリットがあるか」を伝える
- 決めるのは子どもではなく**保護者**。「礼儀・しつけ・心身の強さ」という教育的期待に応える言葉を主役に
- **体験・見学への導線を1本に絞る**（LINE友だち追加＋QRが今は最も摩擦が少ない）
- 曜日・時間・月謝・場所は必ず明記。これがないと「通えるか」が判断できず捨てられる
- **効果測定**：配布エリアごとにQRコードを変える、または「チラシを見た」と言ってもらう仕組みを入れる。どの学区が効いたかが分かれば、次から集中投下できます

## 4. 明日から動くなら（最短手順）

1. jSTAT MAPに登録し、道場中心に半径1.5kmの円 → 町丁目別の0〜14歳人口を出す（30分）
2. 既存門下生の住所をGoogleマイマップにプロット（30分）
3. 1と2が重なるエリアから、**1回2時間で終わる区画**に分割してマイマップに色分け（1時間）
4. GPSロガーアプリとタウンノートをスマホに入れる（5分）
5. 指サック（100均）と斜め掛けバッグを用意（当日）
6. 土曜10時から1区画、GPSログをONにして配る → 帰って区画を「済」に塗る
