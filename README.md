# 配布マップ — iPhone用ポスティング記録アプリ

配り終わった道を地図に残していくWebアプリです。記録のしかたは2通りあります。

- **GPSで自動**：歩いた軌跡がそのまま線になる
- **指で手描き**：あとから地図をなぞって「このへんは配った」と塗っていく

記録はすべて **チラシの版（バージョン）・日付・枚数** に紐づきます。
版ごとに色が変わるので、「春号はここまで、秋号はここまで」が地図で一目で分かります。

**Mac不要・App Store不要・年会費不要。** ファイルをネット上に置いて、
iPhoneのホーム画面に追加するだけで、普通のアプリのように使えます。

## セットアップ

### 手順1：ファイルをネット上に置く

`index.html` は**HTTPSのURLで開く必要があります**。
（iPhoneはセキュリティ上、ファイルを直接開いた状態ではGPSを使わせてくれません）

置き場所は無料で作れます。パソコンのブラウザだけで完結し、Macも開発ツールも要りません。

#### おすすめ：GitHub Pages（無料・ずっと使える）

1. <https://github.com> でアカウントを作る（無料）
2. 右上の「＋」→ **New repository**
3. Repository name に `posting-map` と入力、**Public** を選んで **Create repository**
4. 次の画面の **uploading an existing file** をクリック
5. `index.html` `manifest.webmanifest` `icon-*.png`（5つ）を**まとめてドラッグ＆ドロップ**
   → **Commit changes**
6. 上のタブの **Settings** → 左メニューの **Pages**
7. Branch を **main** / **/(root)** にして **Save**
8. 1〜2分待つと、同じページに URL が表示されます
   → `https://（あなたのID）.github.io/posting-map/`

> リポジトリを Public にすると、URLを知っている人は誰でもアプリを開けます。
> ただし**配布記録のデータはあなたのiPhoneの中だけ**に保存されるので、他人には見えません。

#### もっと早く試したいとき：Netlify Drop

<https://app.netlify.com/drop> にフォルダごとドラッグするだけで即URLが発行されます。
アカウントを作らないと数時間で消えるので、まず動きを確かめる用に。

---

### 手順2：iPhoneに入れる

1. **Safari** で手順1のURLを開く（Chromeではなく必ずSafari）
2. 下の **共有ボタン（□に↑）** をタップ
3. **「ホーム画面に追加」** をタップ
   → 名前が「配布マップ」、アイコンが紺色のチラシのマークになっていることを確認して **追加**
4. ホーム画面にできたアイコンから起動する（アドレスバーのない全画面で立ち上がります）

> アイコンが白紙や地図のスクリーンショットになる場合は、`icon-180.png` が
> `index.html` と同じ階層に上がっているか確認してください。
> 一度ホーム画面に追加したあとにアイコンを差し替えたときは、
> 古いアイコンを削除してから追加し直すと反映されます。

> ホーム画面から起動すると、Safariのタブとは別扱いになり、
> **記録データが7日で消えることもなくなります**。必ずこの形で使ってください。

### 手順3：iPhone側の設定を2つだけ

- **位置情報を許可**（GPS記録を使う場合）
  初回に出るダイアログで **「Appの使用中は許可」**、あわせて **「正確な位置情報」をオン**。
  後から変えるときは `設定 → プライバシーとセキュリティ → 位置情報サービス` から。
  ※手描きだけで使うなら位置情報は不要です。

- **自動ロックの保険**（任意）
  アプリはWake Lockで画面を点けたままにしますが、うまく効かない端末もあります。
  心配なら `設定 → 画面表示と明るさ → 自動ロック → なし` にしておくと確実です。

## 2つのモード

画面下のタブで切り替えます。左の **GPS記録** と、区切り線をはさんだ右の
**なぞる・囲む・消す（＝ログ入力）** の2グループです。

---

### GPS記録モード — 配りながら使う

歩きながら自動で軌跡を残すモード。上部に枚数・距離・稼働時間・**枚/時**が出ます。

1. **「記録スタート」**を押す
2. 1軒投函するごとに、右下の**大きな丸**をタップ（押し間違えは左の **−1**）
3. 終わったら **「記録ストップ」**

**iPhoneのWebアプリは、他のアプリに切り替えたり画面がロックされている間はGPSが止まります。**
これはAppleの制限で回避できません。記録中はこの画面を出したままにしてください。
首下げホルダーか、チラシバッグの外ポケットに**画面を上向き**で挿すのが実用的です。
画面を点けっぱなしにするのでバッテリーを食います。モバイルバッテリーを持ってください。

途中でアプリが裏に回っても、戻ってくれば**自動で記録を再開**します。
その間の区間は線をつながないので、どこが抜けたかも分かります。

---

### ログ入力モード — 帰ってから使う

**なぞる／囲む／消す** のどれかを選ぶと、このモードになります。
記録スタートも枚数カウンターも数字の表示も消えて、**地図が画面の8割まで広がります。**
操作は下の1行（☰ / 現在地 / 記録日 / ひとつ戻す）だけです。

- **なぞる** … 1本指で地図をなぞると、その道が「配った道」として線になります（色はいま選んでいる版の色）
- **囲む** … 1本指でぐるっと囲むと、その範囲が面で塗られます。「この区画は丸ごと配った」用
- **消す** … 手描きした線や面をタップで消します。GPSの記録はここでは消えません

いずれも **2本指なら地図の移動・拡大**です（1本指は描画に使うため、地図のドラッグは切っています）。
操作方法は地図の上に小さく浮かせて表示しています。

GPSを使わないのでバッテリーも食わず、配布中にスマホを見る必要もありません。

**このモードでは枚数は入力しません。** 枚数は ☰メニューの一覧からまとめて入れます（下記）。

---

## あとからまとめて記録するとき

### 1. 配った範囲を地図に入れる

1. チラシのバーで**その日に配った版**に切り替える
2. **なぞる**（または**囲む**）を選び、下の **記録日** を**実際に配った日**に変える
3. 地図をなぞる／囲む

### 2. 枚数を入れる

**☰メニュー →「日ごとの記録・枚数の入力」** を開きます。
日付ごとに、その日使った版が並んでいるので、**数字の欄に直接枚数を打ち込む**だけです。

地図に記録がない日でも、下の **「日付を追加して枚数を入れる」** から日付を選べば行が増えます。
配った範囲は覚えていないが枚数だけ分かる、という日もこれで記録できます。

> GPS記録中にカウンターで数えた分は、この欄にすでに含まれています。
> 欄の数字を書き換えると「その日・その版の合計」がその数になるよう調整されます
> （たとえば320とタップした日に「350」と入れれば合計350枚になります）。

版と日付さえ合っていれば、いつ入力しても集計は正しくなります。

## チラシの版（バージョン）の管理

画面下の**チラシ名のバー**をタップすると、版の一覧が開きます。

- **＋新しい版を追加** … 「2026春・少年部体験」のように名前をつける
- **編集** … 名前と、地図での色（6色から選択）を変える
- **使う** … 記録先の版を切り替える。以降のGPS記録・手描き・枚数はすべてこの版に入ります
- 各行に **合計枚数・距離・配布した期間** が出ます

右の **「全部表示 / この版だけ」** で、地図の表示を絞り込めます。
版が増えて色が見分けにくくなったら、これで1つずつ確認してください。

GPS記録モードのカウンターの丸の**フチの色**が、いま数えている版の色です。切り替え忘れの防止になります。

### 版の色

初期の4色（青・赤・緑・紫）は、色覚特性のある人でも見分けがつき、かつ地図の上で十分に濃い色を
検証したうえで選んでいます。5色目以降（青緑・黄）はやや薄いので、**線の種類（実線・破線・点線）でも
区別できる**ようにしてあります。

**線の上を歩かなければ、その版については重複配布になりません。** これがこのアプリの目的です。

記録中のGPS軌跡も、選んでいる版の色で描かれます（保存済みのものより濃く出ます）。

## 配り漏れチェック

☰メニューの **「配り漏れチェック」** で使えます。まず共通の設定を2つ。

1. **商圏の中心** を設定する（「地図の中心」か「現在地」。ふつうは道場の場所）
2. **商圏の半径** を選ぶ（500m / 1km / 1.5km / 2km）

そのうえで **表示のしかた** を3つから選びます。

---

### 「エリア」— 道路データ不要、すぐ使える

商圏の円が薄く暗くなり、**通った道の左右15mずつ（合計30m）だけが明るく抜けます。**
暗いまま残っている所が、まだ配っていない所です。

道路データを使わず「歩いた線から30mの外＝まだ行っていない」と塗るだけなので、
**行き止まり・私有地・河川敷も暗く残ります。** あくまで目安です。
帯の幅は `index.html` の `const FOG_M = 30;` で変えられます。

---

### 「道路」— 実際の道を1本ずつ判定（おすすめ）

先に道路データを取り込むと使えます。実際の道を25m前後の区間に切り、
**近くに建物がある区間だけ**を配布対象にして、赤（未配布）と灰色（配布済み）で塗り分けます。

- 公園の遊歩道・河川敷・工場の構内道路は、そばに建物がないので**自動的に対象外**になります
- ☰メニューの集計表に **版ごとの配布率** が出ます
- 「商圏内の配布対象 124.1km のうち、未配布 109.4km（7,336区間）」のように**数字で分かります**
- 見やすさのため、このモードでは軌跡の線は表示しません（道路の色分けが同じ情報を持つため）

判定は「歩いた線から20m以内の道は配った」という単純な方式です。
GPSの誤差が8m程度あっても、歩いた道を取りこぼす確率はほぼゼロでした。
すぐ横の歩道や路地も一緒に配布済みになりますが、実際にその前を歩いているので問題ありません。

#### 道路データの取り込み方（1回だけ）

**方法A：アプリから直接**
「Overpassから取得」を押すと、商圏の範囲の道路と建物を取ってきて、その場で計算します。
通信は初回だけで、以降はオフラインで動きます。

**方法B：ファイルから**
うまく取得できないときは、<https://overpass-turbo.eu> で自分で取ってから読み込めます。
地図を商圏に合わせて、次の2つを実行し、それぞれ「エクスポート → データ → 生データを直接ダウンロード」。

```
[out:json][timeout:180];way["highway"]({{bbox}});out geom;
```
```
[out:json][timeout:180];(way["building"]({{bbox}});relation["building"]({{bbox}}););out center;
```

保存した2つのファイルを「ファイルから読み込む」でまとめて選んでください。
建物のファイルは無くても動きますが、入れると対象外の道を自動で除けます。

#### 道路の種類について

OSMでは道が種類分けされています。ポスティングで関係するのは主にこの3つです。

| タグ | 意味 | 例 |
|---|---|---|
| `residential` | 住宅地の生活道路。名前の付いた普通の道 | 家が並ぶ2車線未満の道 |
| `service` | 敷地内や建物へ入るための道 | 私道、駐車場の通路、団地やマンションの構内路 |
| `footway` | 歩行者専用の道 | 歩道、路地、階段の無い抜け道、公園の園路 |

**この3つを必ず含めるのが重要です。** 実データで確認したところ、`residential` だけを見ると
建物の17%が「最寄りの道から40m以上離れている」ことになってしまい、
細い路地や私道沿いの家がまるごと対象から抜け落ちます。
`service` と `footway` を含めると **99.8%の建物が道から40m以内**に収まりました。
日本の住宅地の路地は、多くがこの2つとして登録されています。

そのほか `unclassified`（名前のない細街路）、`tertiary`／`secondary`／`primary`（幹線に近い道）、
`path`・`steps`（小道・階段）も対象にしています。高速道路や自動車専用道
（`motorway`・`trunk`）は、そもそも配れないので除外しています。

#### 限界

- OSMに登録されていない道は判定できません（都市部の路地はおおむね登録されていますが、地域差があります）
- 「その道を通った」ことは分かりますが、**全戸に入れたか**は分かりません。
  大きなマンションを飛ばしても、その道は配布済みになります
- 道路データはバックアップ（JSON）には含めません。機種変更後は取り込み直してください（ボタン一つです）

道路データは [OpenStreetMap](https://www.openstreetmap.org/copyright) 提供（ODbL）です。

## 記録の間隔とバッテリー

☰メニューの **「GPS記録 → 記録の間隔」** で、何秒に1点残すかを選べます（**初期値 10秒**）。

徒歩で配りながらなら10秒で十分です。実際に120秒・132mをL字に歩いた条件で測ると、
点の数は減っても線のずれはごくわずかでした。

| 間隔 | 記録された点 | 実際に歩いた道からの最大ずれ |
|---|---|---|
| 3秒 | 30点 | 2.3m |
| 5秒 | 25点 | 0.1m |
| **10秒** | **13点** | **3.9m** |
| 20秒 | 7点 | 5.2m |

線の太さが約12mなので、10秒なら見た目にはまず分かりません。

**曲がり角だけは間隔を待たずに記録します。** 向きが50度以上変わったら、
間隔の途中でも1点残すようにしてあるので、角が丸まって隣の道にはみ出すことがありません。
記録を止めたときも、最後の位置を書き足して線が途中で切れないようにしています。

### バッテリーについて正直なところ

間隔を長くすると、**線の描き直しやアプリの処理は確実に軽くなります**。
ただし **GPSそのものの消費電力はあまり変わりません。**
Web標準のGeolocation APIには測位の頻度を指定する仕組みがなく、
`enableHighAccuracy` を切る以外に受信機を休ませる方法がないためです
（切ると精度が数百mになり、道単位の記録には使えません）。

ポスティング中に一番電池を使うのは、Wake Lockで**点けっぱなしにしている画面**です。
効くのはこの3つです。

1. 画面の明るさを下げる（屋外で見える範囲でいちばん暗く）
2. モバイルバッテリーを持つ
3. **そもそもGPSを使わず、帰ってから「ログ入力モード」でなぞる**

3が一番確実です。慣れてくると、配った範囲は覚えているものです。

## ☰メニューでできること

- **配り漏れチェック**（なし / エリア / 道路 の切替、商圏の中心と半径、道路データの取り込み）
- **記録の間隔**（3 / 5 / 10 / 20秒。初期値10秒）
- **地図の切り替え**（淡色 / 標準 / 航空写真 / OpenStreetMap）
  - 集合住宅の入口やポストの位置を探すときは**航空写真**が便利です
- **線の太さを実際の幅に合わせる**（初期値ON）
  - ONだと線が「実際に配った幅（約12m）」を表すので、ズームしても見え方が変わりません
  - OFFにすると常に細い線になります
- **チラシの版ごとの集計**（枚数・距離・日数・期間の一覧）
- **日ごとの記録・枚数の入力**（版ごとの内訳、枚数の直接入力、日付の追加、地図での表示・削除）
- **CSVで書き出し** … `日付 / チラシの版 / 枚数 / GPS距離km / 手描き距離km / 手描き件数`。
  Excelやスプレッドシートに貼って、版ごとの反響率（体験申込÷配布枚数）を出すのに使えます
- **JSONで書き出し**＝バックアップ、**GPXで書き出し**＝他の地図アプリで開く用

## データの保存について

記録は **このiPhoneの中だけ** に保存されます（サーバーには一切送りません）。

### アプリ側でやっていること

- **起動時に `navigator.storage.persist()` で永続化を要求**しています。
  WebKitは「ホーム画面Webアプリとして開かれているか」などを見て許可を判断するため、
  **ホーム画面のアイコンから起動していると通りやすくなります**（iOS 15.2以降で対応）。
  許可されると、空き容量が減ったときの自動削除（LRUによる eviction）の対象から外れます。
- ☰メニューの **「データの安全」** で、いまの状態を確認できます。
  - 保存の永続化：有効／未許可（未許可なら「要求する」でもう一度要求できます）
  - ホーム画面から起動中か、Safariのタブで表示中か
  - 使用量と、最後にバックアップした日
- Safariのタブで開いている場合は**警告を出します**。
  タブのままだと7日間使わないとデータが消えることがあります。
- 保存データが壊れて読めなかったときは、**そのまま上書きせず別キーに退避**します。
  「読み込めなかったデータを書き出す」から中身を取り出せます。
- 最後のバックアップから30日経つと、**書き出しボタンに印が付いてお知らせ**します。

### それでも自分でバックアップしてください

永続化はあくまで「自動削除されにくくなる」だけで、次のケースでは消えます。

- ホーム画面のアイコンを削除した
- 設定から「履歴とWebサイトデータを消去」した
- 機種変更した／端末を初期化した

月に一度、**☰メニュー →「JSONで書き出し」** を押して、
「ファイル」アプリやiCloud Driveに保存しておいてください。
復元は「JSONを読み込み」からできます（重複は自動でスキップされます）。

## 直したいとき

`index.html` をテキストエディタで開けば全部書いてあります。
GitHubの画面上で直接編集（鉛筆アイコン）してCommitすれば、数十秒でアプリに反映されます。

よく変えたくなりそうな値：

| 場所 | 意味 |
|---|---|
| `const WIDTH_M = 12;` | 線として描く「配った幅」（メートル） |
| `const FOG_M = 30;` | 「エリア」表示で配れたとみなす帯の幅（メートル） |
| `const SNAP_M = 20;` | 「道路」表示で、線からこの距離内の道を配布済みにする |
| `const SEG_M = 25;` | 道路を切る区間の長さ（短くすると細かく、データは増える） |
| `const NEAR_B = 30;` | 建物がこの距離内にある道だけを配布対象にする |
| `if(acc > 40) return;` | GPSの精度がこれ（m）より悪い点は捨てる |
| `const MIN_D = 4;` | 前の点からこれ（m）動かないと、止まっているとみなす |
| `const TURN_DEG = 50;` | 向きがこれ（度）以上変わったら、間隔を待たず角を記録する |
| `const INTERVALS = [3,5,10,20];` | メニューに出す間隔の選択肢（秒） |
| `--accent:#ff6a1f;` | カウンターの色 |
| `const PALETTE = [...]` | 版に使える6色と線の種類。順番が新しい版に割り当たる順です |

## アイコンを変えたいとき

`app-icon.svg` がアイコンの元データです。テキストエディタでも開けます。

| 部分 | 該当箇所 |
|---|---|
| 背景の紺 | `#16203a` → `#28375f` のグラデーション |
| 道とチラシの白 | `#ffffff` |
| 現在地とチラシの見出しのオレンジ | `#ff6a1f` |

編集したら、SVGを画像に書き出すサイトなどで **180 / 192 / 512** の3サイズのPNGを作り、
同じファイル名で置き換えてください。
